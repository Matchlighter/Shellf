Shellf — a shell for boxes you can't install on

One command drops a real shell and a set of static tools onto a locked-down server. Nothing installs until you ask for it. Pick a shell, then copy the line.

Default shell

Why zsh is the big one

zsh doesn't ship as a single static binary the way the other two do. romkatv/zsh-bin publishes a relocatable tree instead: bin/zsh plus the share/zsh function library it loads at runtime — completions, compinit, prompt helpers. That is 1,163 function files out of about 4,100 in total. Without them zsh starts, and not much else works.

So installing it unpacks 23.7 MB into $SHLF_HOME/tools/zsh.d and drops a one-line shim at tools/zsh, so the core still finds one executable where it expects one. Over the wire it is 3.6 MB.

For comparison, fish is a single 14.1 MB binary with its data files built in, and bash is 2.3 MB. zsh is also the only tool here that needs the mod_install hook.

How this gets chosen

  1. This field, if you fill it in. It has to be writable and allow exec, or shlf stops rather than half-installing somewhere useless.
  2. Otherwise, if shlf is already installed at <dir>/bin/shlf, it reuses <dir>. That is how a second run, or a tool linked onto PATH, finds the same cache with nothing exported.
  3. Otherwise the first of these that passes:
    • $XDG_CACHE_HOME/shlf, else ~/.cache/shlf
    • ~/.shlf
    • /dev/shm/shlf-<uid>
    • /tmp/shlf-<uid>
    • ./.shlf
  4. If none of them pass, it stops and asks you to set this.

Passing means it wrote a small script there and ran it, so a noexec /tmp is ruled out now rather than failing later.

Locked means mirror only: it fails rather than reaching upstream. SHLF_MIRROR_ONLY=1

Presets

    · ·

    Pipe needs curl or wget on the box. Paste carries the same client detection inline, so it works with only Ruby, Python, Perl, or busybox, and tells you plainly when the box has none of them. Each tool is a module under /mods/, fetched the first time you ask for it and cached after that. curl and busybox are linked like the rest but defer to the box's own copy when there is one, so putting them on PATH never costs a download and never shadows a working client.
